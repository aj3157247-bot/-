# دانشجویان — پلتفرم آموزشی چندزبانه افغانستان

نسخه اولیه قابل اجرا (MVP) برای وب‌سایت «دانشجویان» با رابط فارسی/دری، پشتو و انگلیسی.

## امکانات موجود
- رابط کاربری واکنش‌گرا با رنگ‌های روشن و مدرن
- انتخاب زبان فارسی/دری، پشتو و انگلیسی؛ راست‌چین برای فارسی و پشتو و چپ‌چین برای انگلیسی
- فهرست نمونه دانشگاه‌ها، رشته‌ها، سمسترها و مضمون‌ها
- ثبت‌نام و ورود دانشجو
- صفحه پروفایل دانشجو
- بارگذاری منابع درسی با وضعیت «در انتظار بررسی»
- پنل ساده مدیر برای تأیید یا رد منابع
- دریافت فایل‌های تأییدشده
- ذخیره داده‌ها در SQLite
- محدودیت نوع فایل و حجم (۱۵ مگابایت)، هش رمز عبور و محدودسازی تلاش‌های ورود

## پیش‌نیاز
- Node.js نسخه 20 یا جدیدتر
- اینترنت برای نصب اولیه وابستگی‌ها و بارگذاری فونت وب (در صورت قطع اینترنت، فونت جایگزین استفاده می‌شود)

## اجرا در کامپیوتر
1. فایل ZIP را استخراج کنید.
2. ترمینال را در پوشه پروژه باز کنید.
3. فایل `.env.example` را به `.env` کپی کنید.
4. مقادیر `SESSION_SECRET`، `ADMIN_EMAIL` و `ADMIN_PASSWORD` را تغییر دهید.
5. دستورها را اجرا کنید:

   ```bash
   npm install
   npm start
   ```

6. در مرورگر آدرس `http://localhost:3000` را باز کنید.

در اولین اجرا، پوشه `data` و پایگاه داده به‌صورت خودکار ساخته می‌شوند. سه دانشگاه و چند رشته/مضمون نمونه نیز برای نمایش ساختار اضافه شده‌اند.

## اجرا در ویندوز
- Node.js را از وب‌سایت رسمی آن نصب کنید.
- PowerShell را در پوشه پروژه باز کنید.
- فایل تنظیمات را بسازید:

  ```powershell
  Copy-Item .env.example .env
  notepad .env
  npm install
  npm start
  ```

## مدیر سایت
در `.env` یک ایمیل و رمز قوی برای مدیر تعیین کنید. حساب مدیر در اولین اجرا ساخته می‌شود. اگر پایگاه داده از قبل ساخته شده باشد، تغییر این مقادیر به‌تنهایی رمز مدیر قبلی را عوض نمی‌کند.

## نکات مهم پیش از انتشار عمومی
این بسته یک MVP برای شروع توسعه است، نه سامانه آماده مقیاس میلیونی. پیش از انتشار عمومی:
- `SESSION_SECRET` را با یک مقدار تصادفی طولانی جایگزین کنید.
- از HTTPS استفاده کنید و تنظیمات کوکی امن را حفظ کنید.
- برای محیط چندسروری، ذخیره‌سازی session را از MemoryStore پیش‌فرض به Redis یا سرویس پایدار منتقل کنید.
- فایل‌ها را به فضای ذخیره‌سازی امن و اسکن بدافزار منتقل کنید؛ در این نسخه فایل‌ها روی دیسک سرور ذخیره می‌شوند.
- سیاست حریم خصوصی، شرایط استفاده، گزارش محتوا، پشتیبان‌گیری و روند حذف محتوا را اضافه کنید.
- CSRF protection، تأیید ایمیل، بازیابی رمز عبور، مدیریت نقش‌های پیشرفته و ثبت رویدادهای مدیریتی را قبل از استفاده گسترده اضافه کنید.
- داده‌های نمونه را با فهرست رسمی دانشگاه‌ها، برنامه‌های درسی تأییدشده و محتوایی که مجوز انتشار آن را دارید جایگزین کنید.
- برای محتوای آموزشی از کتاب‌ها و جزوه‌هایی استفاده کنید که حق نشر آن‌ها اجازه انتشار عمومی می‌دهد.

## توسعه بعدی پیشنهادی
- پنل مدیریت برای ساخت/ویرایش دانشگاه‌ها، رشته‌ها و مضمون‌ها
- تأیید ایمیل و بازیابی رمز عبور
- صفحات عمومی اختصاصی رشته و مضمون با URL مستقل
- جست‌وجوی تمام‌متن فارسی، پشتو و انگلیسی
